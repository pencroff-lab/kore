# Examples

Executable examples for each module, generated from the library's
`*.examples.test.ts` files. They are regenerated by `bun run docs:generate`;
do not edit them by hand.

- [flow](flow.md) — Boundaries, the callback protocol, transformations, pipelines, collections, serialization, and input protection.
- [flow test helpers](test.md) — Asserting on result tuples with expectOk and expectErr.
- [Err](err.md) — Error creation, wrapping, codes, metadata, and serialization.
- [Outcome](outcome.md) — Mapping, piping, combinators, and error handling (deprecated tier).
- [dtStamp](format_dt.md) — Compact, sortable date and time stamps.
- [Logger](logger.md) — Log levels, transports, child loggers, and Err integration.
